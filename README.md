# Vitaminise

Навчальний frontend-проєкт — адаптивний лендінг для концептуального сервісу страхування Vitaminise.

## 📌 Про проєкт

Vitaminise — це вебсторінка, присвячена онлайн-сервісу страхування. Основна ідея дизайну — показати простий і зручний спосіб оформлення страхового полісу, онлайн-оплати та взаємодії з клієнтською підтримкою.

Проєкт створений з метою практичного закріплення навичок HTML та CSS, роботи з макетом і побудови адаптивних вебсторінок.

## ✨ Основні секції

- **Головний екран** — знайомство із сервісом Vitaminise.
- **Про Vitaminise** — основні переваги сервісу.
- **Страхові продукти** — огляд доступних страхових пропозицій.
- **Як оформити страхування** — візуальне представлення процесу оформлення поліса.
- **Про страхування** — інформація про принцип роботи сервісу.
- **Футер** — логотип, інформація про мобільний застосунок і навігація.

## 🛠 Використані технології

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts

## 📱 Адаптивність

Під час розробки використовувалися медіазапити для адаптації сторінки до мобільних пристроїв.

Для побудови макета застосовувалися Flexbox, CSS Grid та гнучкі розміри елементів.
